\chapter*{Resumen}
\addcontentsline{toc}{chapter}{Resumen}
Este trabajo presenta el dise\~no y desarrollo de un sistema basado en modelos de lenguaje para realizar an\'alisis financiero hist\'orico a partir de consultas formuladas en lenguaje natural. El objetivo no es predecir la evoluci\'on del mercado, sino estudiar c\'omo integrar un LLM en un flujo de trabajo en el que los c\'alculos puedan ejecutarse, revisarse y conservarse como evidencia.

El sistema recibe una consulta junto con informaci\'on estructurada sobre los activos, el periodo analizado y los ficheros CSV disponibles. A partir de esta entrada, un primer agente elabora un plan anal\'itico; un segundo agente genera el c\'odigo Python necesario; y un tercer agente interpreta los resultados calculados. Entre estas etapas se aplican validaciones de entrada, controles sobre el c\'odigo generado y una ejecuci\'on en un proceso separado. El flujo conserva el plan, el script, la salida estructurada y los registros de error, lo que permite localizar en qu\'e etapa se produce un fallo.

Para comprobar el funcionamiento del sistema se ha definido una bater\'ia de consultas con distintos niveles de dificultad y requisitos anal\'iticos. La evaluaci\'on contempla tanto la finalizaci\'on del flujo como la calidad de las respuestas, la correcta utilizaci\'on de los datos y la gesti\'on controlada de los errores. De este modo, el trabajo propone una aproximaci\'on reproducible para estudiar la integraci\'on de modelos de lenguaje, generaci\'on de c\'odigo y an\'alisis financiero, manteniendo la trazabilidad del proceso y evitando la formulaci\'on de recomendaciones de inversi\'on.

\vspace{0.5cm}
\noindent\textbf{Palabras clave:} an\'alisis financiero hist\'orico, modelos de lenguaje, generaci\'on de c\'odigo, agentes LLM, ejecuci\'on controlada, trazabilidad.

\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}
This work presents the design and development of a language-model-based system for historical financial analysis from natural-language queries. Its purpose is not to predict market behaviour, but to examine how an LLM can be integrated into a workflow in which calculations are executed, reviewed and retained as evidence.

The system receives a query together with structured information about the requested assets, time period and available CSV files. A first agent produces an analytical plan, a second agent generates the required Python code, and a third agent explains the calculated results. Input validation, code checks and execution in a separate process are applied between these stages. The workflow retains the plan, generated script, structured output and error logs, making it possible to identify the stage at which a failure occurs.

To examine the operation of the system, an evaluation set was defined with queries covering different levels of difficulty and analytical requirements. The assessment considers workflow completion, response quality, appropriate use of the available data and controlled error handling. The work therefore provides a reproducible approach for studying the integration of language models, code generation and financial analysis while preserving process traceability and avoiding investment recommendations.

\vspace{0.5cm}
\noindent\textbf{Keywords:}\\
historical financial analysis, language models, code generation, LLM agents, traceability.
