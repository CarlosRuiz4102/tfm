\chapter*{Resumen}
\addcontentsline{toc}{chapter}{Resumen}
Este trabajo estudia el dise\~no de un sistema multiagente basado en modelos de lenguaje para realizar an\'alisis financiero hist\'orico a partir de consultas formuladas en lenguaje natural. El foco del proyecto no est\'a en predecir el mercado, sino en organizar un flujo trazable en el que la petici\'on se transforme en una estructura de datos interpretable, se validen los datos necesarios, se genere c\'odigo ejecutable, se controle su ejecuci\'on y se redacte una respuesta final apoyada en evidencias.

La memoria queda preparada para documentar ese recorrido por etapas. En particular, se refuerzan la metodolog\'ia, la descripci\'on del flujo y el marco de evaluaci\'on, de manera que el trabajo final pueda explicar no solo si el sistema produce respuestas, sino tambi\'en c\'omo llega a ellas, d\'onde falla y qu\'e garant\'ias ofrece cada bloque del proceso.

En esta versi\'on, varias secciones se han dejado como plantilla guiada para completar conforme se implemente y eval\'ue el flujo definitivo. El objetivo es que la memoria final mantenga coherencia entre dise\~no, ejecuci\'on, resultados y limitaciones, y que cada afirmaci\'on importante pueda apoyarse en artefactos observables del sistema.

\vspace{0.5cm}
\noindent\textbf{Palabras clave:} an\'alisis financiero hist\'orico, modelos de lenguaje, generaci\'on de c\'odigo, agentes LLM, ejecuci\'on controlada, trazabilidad.

\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}
This work studies the design of a multi-agent language-model-based system for historical financial analysis from natural-language queries. Rather than predicting market behaviour, the project focuses on defining a traceable workflow in which a request is transformed into structured data, relevant market data are validated, executable code is produced, execution is controlled, and the final answer is grounded in observable evidence.

The dissertation has been prepared so that methodology, workflow description and evaluation can be developed rigorously as the final system is implemented. Several sections are therefore kept as guided templates, allowing the final document to explain not only whether the system works, but also how each stage contributes to robustness, traceability and controlled failure handling.

At this stage, the document provides a coherent structure for reporting the final project, with special emphasis on methodological justification, stage-by-stage analysis and evidence-based evaluation.

\vspace{0.5cm}
\noindent\textbf{Keywords:}\\
historical financial analysis, language models, code generation, LLM agents, traceability.
