GUIA DE CREDENCIALES LLM

Estado actual: el proyecto usa el modelo openai/gpt-oss-20b servido sobre vLLM. vLLM es la infraestructura de inferencia y expone un endpoint compatible con Chat Completions.

1. CONFIGURACION OPENAI

Crear o actualizar el fichero de entorno con:

VLLM_BASE_URL=https://servidor-vllm.example/v1
VLLM_API_KEY=pegar_aqui_la_clave_del_endpoint
VLLM_MODEL=openai/gpt-oss-20b

2. CONFIGURACION OPENAI SERVIDO EN VLLM

Si el modelo se ejecuta en un servidor vLLM compatible con Chat Completions:

OPENAI_BASE_URL=https://servidor-vllm.example/v1
OPENAI_API_KEY=pegar_aqui_la_clave_del_endpoint
OPENAI_MODEL=openai/gpt-oss-20b

3. COMPROBACION

La aplicacion debe poder construir la configuracion LLM y completar una ejecucion de prueba sin descargar datos externos. Los CSV historicos deben existir en el repositorio local.

4. SEGURIDAD

No copiar claves reales en informes, memoria, notebooks ni resultados. Las claves deben permanecer en variables de entorno o ficheros locales no versionados.
